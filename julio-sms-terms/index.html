Program Name

Julio Salas SMS Testing

Program Description

Julio Salas SMS Testing is a voluntary, low-volume transactional messaging program operated by Julio Salas for personal software-development testing. Users who affirmatively opt in may receive software-test messages concerning test food orders, catering requests, payment confirmations, receipt notifications, and application-status updates. No marketing, advertising, promotional, sales, or third-party messages are sent through this program.

Types of Messages

  • Test food-order confirmations
  • Test catering-request confirmations
  • Test payment confirmations
  • Test receipt notifications
  • Application-status updates
  • SMS delivery-testing notifications

Message Frequency

Message frequency varies according to the user's test activity.

Message and Data Rates

Message and data rates may apply, depending on the user's mobile carrier and service plan.

Voluntary Enrollment

Enrollment in Julio Salas SMS Testing is entirely voluntary.

Consent Is Not a Condition of Purchase
